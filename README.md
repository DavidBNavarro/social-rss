# Social RSS — static feeds

Public, static RSS feeds generated by GitHub Actions and served by GitHub Pages. No server, no cold starts, $0.

- X feeds: refreshed daily at 06:00 UTC
- Instagram feeds: refreshed weekly on Monday at 07:00 UTC
- Output: `docs/feeds/<platform>/<handle>.xml`
- Import list: `docs/feeds.opml`

## Add or change handles

Edit `feeds-x.txt` or `feeds-instagram.txt`, one handle per line. Lines starting with `#` are ignored. Commit and run the matching workflow manually from the Actions tab, or wait for the schedule.

## Secrets

Required in Settings → Secrets and variables → Actions:

- `TWITTER_AUTH_TOKEN`: the `auth_token` cookie from a logged-in burner X account.
- `INSTAGRAM_COOKIE`: `sessionid=...; ds_user_id=...` from a logged-in burner Instagram account.

Use dedicated accounts, not your main ones. Keep the browser sessions logged in; logging out invalidates the cookies.

## Pages

Settings → Pages → Source: Deploy from a branch → `main` → `/site`.

Feed URLs:

```
https://<owner>.github.io/<repo>/feeds/x/<handle>.xml
https://<owner>.github.io/<repo>/feeds/instagram/<handle>.xml
```

## Test batch

The first run uses five X handles and five Instagram handles. Confirm both workflows and the image rendering before replacing them with the full list.

## Fallback

If Instagram blocks the GitHub runner IPs or checkpoints the cookie, keep X here and move Instagram to a home device with a residential IP. Do not add a paid proxy.
